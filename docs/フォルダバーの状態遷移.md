# 上部フォルダバーの状態遷移

この資料は、v0.2.1時点の実装におけるフォルダバーの表示と操作を整理したものです。**現在の操作体系は最適化前**であり、今後の実機利用を踏まえて見直す余地があります。機能要件の正本は [統合仕様書 v0.2.1](../specification/specification_v0.2.1.md) です。

## 状態と表示

バーには、表示中と最小化中を含め、保持している全ペインを開いた順に並べます。ペインを最小化・復元しても並び順は変わりません。フォルダ名にポインターを合わせるとパスを表示します。

| ペインの状態 | バーの表示 | ペイン領域 |
| --- | --- | --- |
| 通常表示中 | 表示順の番号とフォルダ名。例: `1: Downloads` | 分割レイアウト内に表示 |
| 最大化中 | 番号とフォルダ名を青色で表示 | そのペインだけを全面表示 |
| 別のペインの最大化で一時的に隠れている | 番号とフォルダ名を通常表示 | 最大化を解除すると再表示 |
| 最小化中 | 番号なしのフォルダ名。点線枠、控えめな色、通常の80%の文字サイズ | 表示レイアウトから外れる |

最小化中のペインと、他のペインの最大化によって一時的に隠れているペインは異なります。後者は表示レイアウトに残り、番号も持ちます。バーの順序は表示順と一致するとは限りません。表示中の番号は追加・削除・最小化・復元で振り直され、ペイン見出しと `Alt+数字`、ブックマークの「Pane Nへ送る」に対応します。同じフォルダを複数開いた場合も別々のボタンとして扱います。

## バーのクリックによる状態遷移

| クリックしたペインの状態 | 操作後 | レイアウト・フォーカス |
| --- | --- | --- |
| 通常表示中 | そのペインを最大化 | 元の分割構造と比率を保持し、対象をアクティブにする |
| 最大化中 | 最大化を解除 | 元の分割レイアウトを表示し、対象をアクティブにする |
| 他のペインの最大化で一時的に隠れている | クリックしたペインの最大化に切り替える | 分割構造と比率を保持し、新しい対象をアクティブにする |
| 最小化中 | 最小化を解除し、通常表示に戻す | 表示中のアクティブペインの右に復元し、復元対象をアクティブにする |
| 最小化中で、表示ペインがない | 最小化を解除し、単独表示する | 復元対象をアクティブにする |

最大化中に最小化ペインをクリックすると、先に最大化を解除し、アクティブペインの右に復元します。最小化前の分割位置には戻りません。

## 関連する操作

| 操作 | バー・ペインへの影響 |
| --- | --- |
| ペインの `−` を押す | 対象を最小化。最大化中なら先に解除する。バーには番号なしで残る |
| ペインの `□` / `❐` を押す | 対象を最大化 / 解除する。バーの状態表示も更新する |
| ペインを追加・閉じる | 最大化中は先に解除する。バーに追加 / バーから削除し、表示中ペインの番号を更新する |
| `Ctrl+Tab` / `Ctrl+Shift+Tab` | 最大化中は最大化を維持し、表示順で次 / 前のペインを最大化する。通常時は次 / 前のペインへ移動する。最小化中は対象外 |
| `Alt+数字` | 最大化中は先に解除し、表示順の番号に対応するペインに移動する。最小化中は対象外 |
| フォルダを移動する | 移動成功後、対応するバーとペイン見出しのフォルダ名・パスを更新する |
| 最後の表示ペインを最小化 / 閉じる | 最小化中のペインが残る場合は、表示ペインがない状態になり、バーから復元できる |

保持するペインがなくなるとアプリは終了します。全ペインを最小化した状態でブックマークを開くと、新規ペインを追加して表示します。ただし、最小化中を含め8ペインの上限に達している場合は追加できません。

## 確認状況と今後の検討

ユーザーは最大化・最小化の実機動作、番号とフォルダ名の表示、および最小化時の文字サイズを確認しています。すべての遷移、同名フォルダ、狭い画面での横スクロールなどの個別条件が実機確認済みであることを意味しません。

番号が振り直される点、状態表示の分かりやすさは、実際の利用に応じて見直す候補です。
