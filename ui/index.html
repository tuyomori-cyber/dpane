キーボードショートカット

ペイン操作のショートカットです。一部はパス欄でも使えます。

キー操作
Ctrl+Shift+Lアクティブペインの右に追加
Ctrl+Shift+Jアクティブペインの下に追加
Ctrl+Shift+Wアクティブペインを閉じる
Ctrl+T更新日時を表示 / 非表示
Ctrl+Kショートカット一覧を開く / 閉じる
Ctrl+Tab / Ctrl+Shift+Tab次 / 前のペインへ移動
Alt+1〜Alt+8表示順の1〜8番目のペインへ移動
Ctrl+Shift+O / Ctrl+Shift+E別のアプリで開く / 実行を確認
Ctrl+C / Ctrl+X / Ctrl+Vコピー / 切り取り / 貼り付け
Delete選択項目をゴミ箱へ移動
Shift+矢印選択範囲を拡大 / 縮小
F2選択項目の名前を変更
↑ / ↓ / ← / →一覧の項目を選択
文字入力 / Ctrl+F名前で一覧を検索
Enter選択項目を開く
Backspace親フォルダへ移動
F5現在のフォルダを更新

一覧の名前検索

↑ / ↓一致候補を前 / 次へ移動
Enter一致項目を開く
Escape検索欄を閉じる

パス欄

Tabフォルダ候補を補完
↑ / ↓補完候補を選択
Enter選択中の候補を反映、または入力パスへ移動
Escape補完候補を閉じる
