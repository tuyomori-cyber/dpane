# Dpane 仕様書 v0.1.18

- 作成日: 2026-11-08
- [v0.1.17](specification_v0.1.17.md) を継承し、ブックマーク機能を追加する。
- ステータス: 実装済み、GUI実機確認待ち

## 1. 目的

頻繁に使用するディレクトリをブックマークとして登録し、素早くアクセスできるようにする。

Dpaneの特徴であるマルチペイン構成を活かし、ブックマークから任意のペインへディレクトリを表示できるようにする。

### 基本方針

- 最小限の機能で実装する。
- 操作方法が直感的に理解できるUIとする。
- ブックマーク一覧は必要なときだけ表示する。
- 既存のペイン操作・レイアウト機能を利用する。
- ブックマークはアプリ終了後も保持する。

## 2. UI構成

### 2.1 ブックマーク一覧

メインツールバーにブックマークボタン「☆」を追加する。

ボタンをクリックすると、ブックマーク一覧をポップアップ表示する。

```text
┌───────────────────────────────┐
│ ☆ ブックマーク                 │
├───────────────────────────────┤
│ 📁 Documents              ⊞   │
│ 📁 Downloads              ⊞   │
│ 📁 Projects               ⊞   │
│ 📁 score                  ⊞   │
└───────────────────────────────┘
```

- ディレクトリ名を一覧表示する。
- 各項目の右側に新規ペインボタン「⊞」を配置する。
- ポップアップ外をクリックすると閉じる。
- ブックマークがない場合は空状態のメッセージを表示する。

### 2.2 ブックマーク登録

各ペインのディレクトリ表示部分に登録ボタンを配置する。

| 状態 | 表示 |
|---|---|
| 未登録 | ☆ |
| 登録済み | ★ |

- ☆をクリックすると現在のディレクトリを登録する。
- ★をクリックすると登録を解除する。
- 同じディレクトリの重複登録は許可しない。
- 登録・解除は即座にUIへ反映する。

## 3. ブックマーク操作

### 3.1 左クリック

ブックマーク名を左クリックすると、アクティブペインで対象ディレクトリを開く。

アクティブペインが存在しない場合は、新規ペインを作成して開く。

### 3.2 新規ペインボタン

ブックマーク項目右側の「⊞」をクリックすると、新規ペインを追加して対象ディレクトリを開く。

既存のペインは変更しない。

新規ペインの配置にはDpane既存のレイアウト処理を使用する。

### 3.3 右クリック

ブックマーク項目を右クリックすると、コンテキストメニューを表示する。

```text
┌─────────────────────┐
│ 開く                │
│ 新規ペインで開く     │
│ 送る             ▶  │
│─────────────────────│
│ ブックマークを削除   │
└─────────────────────┘
```

#### 「送る」サブメニュー

「送る」にカーソルを合わせると、現在開いているペインを一覧表示する。

```text
送る ▶ ┌─────────────┐
       │ Pane 1      │
       │ Pane 2      │
       │ Pane 3      │
       └─────────────┘
```

- ペイン一覧はメニュー表示時点の状態を反映する。
- ペインを選択すると、そのペインの表示ディレクトリを変更する。
- 他のペインには影響しない。
- ペイン番号は現在の画面上の表示順に対応させる。
- ペインが存在しない場合、「送る」は無効化する。

「送る」はファイルのコピー・移動ではなく、指定ペインの表示ディレクトリを切り替える操作とする。

## 4. データ保存

### 4.1 保存形式

JSON形式で永続保存する。

保存先の例：

`~/.config/dpane/bookmarks.json`

データ構造：

```json
{
  "version": 1,
  "bookmarks": [
    {
      "path": "/home/user/Documents"
    },
    {
      "path": "/home/user/Downloads"
    },
    {
      "path": "/home/user/Projects"
    }
  ]
}
```

### 4.2 保存ルール

- ディレクトリの絶対パスを保存する。
- 表示名はディレクトリ名から自動生成する。
- 登録順を保持する。
- 登録数に固定上限は設けない。
- 登録・解除時に保存する。
- 起動時に保存データを読み込む。

### 4.3 パスの扱い

- 登録時にパスを正規化する。
- 同じ実体を指すディレクトリの重複登録を防ぐ。
- 存在しなくなったディレクトリもブックマーク一覧には残す。
- 開く際に存在確認を行い、アクセスできない場合はエラーを表示する。
- エラー発生時は現在のペイン表示を変更しない。

## 5. ペインとの連携

既存のペイン管理機能を利用する。

| 操作 | 既存ペイン | 新規ペイン |
|---|---|---|
| 左クリック | アクティブペインを変更 | アクティブペインがない場合のみ |
| ⊞クリック | 変更しない | 追加 |
| 右クリック → 開く | アクティブペインを変更 | アクティブペインがない場合のみ |
| 右クリック → 新規ペイン | 変更しない | 追加 |
| 右クリック → 送る | 指定ペインを変更 | 追加しない |

ペインの追加・削除・再配置は既存のDpaneの処理に委ねる。

## 6. 実装方針

### フロントエンド

既存のHTML/CSS/JavaScriptに機能を追加する。

- ブックマークポップアップ
- ☆ / ★ 登録状態表示
- 新規ペインボタン
- 右クリックコンテキストメニュー
- 「送る」サブメニュー
- 登録・解除時のUI更新

サブメニューはホバーで展開する。

マウス移動中にサブメニューが意図せず閉じないよう、親メニューとサブメニューのポインター移動領域を考慮する。

画面端ではメニューの表示位置を調整し、画面外にはみ出さないようにする。

### バックエンド

既存のPythonバックエンドにブックマーク管理処理を追加する。

必要な処理：

- ブックマーク一覧取得
- ブックマーク登録
- ブックマーク解除
- JSONファイル読み書き
- ディレクトリの存在・アクセス確認

JSON保存は一時ファイルへの書き込み後に置き換える方式とし、保存途中の破損を防止する。

ブックマーク経由のディレクトリ移動には、既存のディレクトリ表示処理を再利用する。

## 7. 初期バージョンで実装しない機能

以下はv0.1.18の対象外とする。

- ブックマークのフォルダ分類
- ブックマークの名前変更
- ドラッグ＆ドロップによる並べ替え
- ブックマークのインポート・エクスポート
- クラウド同期
- ブックマーク検索
- ブックマーク専用サイドバー
- ペイン構成全体の保存・復元

必要になった段階で追加を検討する。

## 8. 動作確認項目

1. 現在のディレクトリを☆で登録できる。
2. 登録済みディレクトリでは★が表示される。
3. ★をクリックすると登録解除できる。
4. 左クリックでアクティブペインが切り替わる。
5. ⊞クリックで新規ペインが追加される。
6. 右クリックでコンテキストメニューが表示される。
7. 「送る」で現在のペイン一覧が表示される。
8. 指定したペインだけが対象ディレクトリに切り替わる。
9. ペイン追加・削除後も正しいペインを選択できる。
10. Dpane再起動後もブックマークが保持される。
11. 存在しないディレクトリを開こうとしても異常終了しない。
12. 同じディレクトリを重複登録できない。

## 9. 完了条件

以下を満たした時点でv0.1.18のブックマーク機能を完成とする。

- ブックマークの登録・解除ができる。
- アクティブペインで開ける。
- 新規ペインで開ける。
- 右クリックから任意の既存ペインを指定できる。
- ブックマークが永続保存される。
- 既存のペイン操作に悪影響がない。

---

**設計方針：ブックマークはディレクトリへのショートカットであり、ペイン管理機能そのものは持たせない。**

Dpane既存のペイン操作を組み合わせることで、少ない追加機能で柔軟なディレクトリアクセスを実現する。
