# Dpane 仕様書 v0.1.19

- 作成日: 2026-11-08
- [v0.1.18](specification_v0.1.18.md) を継承し、選択表示と既定アプリの変更を追加する。
- ステータス: 実装済み。選択解除、選択色の区別、既定アプリ変更の3件についてユーザーが動作確認済み。

## 選択と表示

- 一覧の空白を左クリックすると、そのペインの項目選択を解除する。ほかのペインには影響しない。
- アクティブペインの選択項目と、非アクティブペインの選択項目を異なる色で表示する。

## 既定アプリの変更

- 単一ファイルの右クリックメニューから「既定のアプリを変更」を選び、ファイルの種類ごとのシステムの既定アプリを設定できる。他のアプリにも反映されることをダイアログに示す。
- キャンセル時は関連付けを変更せず、設定時はファイルを自動で開かない。種類を確認できない場合や選択中に変化した場合は設定せず、エラーを表示する。
- 「別のアプリで開く」は従来どおり関連付けを変更せずに開く。実行可能なELFバイナリのダブルクリックは引き続き実行確認とする。

## 受け入れ条件

- [x] 複数項目の選択中に空白を左クリックすると、そのペインの選択が解除される。
- [x] 選択項目のあるペインを切り替えると、選択状態を維持したまま色が変わる。
- [ ] 既定アプリの設定・キャンセル後の動作が上記のとおりで、後の通常ファイルのダブルクリックに反映される。
- [ ] 「別のアプリで開く」は既定アプリを変更しない。

既定アプリ変更そのものはユーザーが動作確認済み。上記のキャンセルや「別のアプリで開く」を含む個別条件の実機確認結果は未記録。
