# dir-group-webUI 仕様書 v0.1.6

- 作成日: 2026-11-04
- [v0.1.5](specification_v0.1.5.md) を継承し、コピー時の同名処理、切り取り時の同名確認、名前変更を追加する。矛盾する場合は本版を優先する。
- 状態: 名前変更を実装済み、実機確認待ち。コピー時の連番と切り取り時の同名確認は未実装。

## 1. コピー時の同名処理

- コピーを貼り付ける際、貼り付け先に同名の項目がなければ元の名前で作成する。
- 同名のファイル・フォルダ・シンボリックリンクがある場合は、既存項目を上書き・結合せず、空いている連番付きの名前を自動的に選ぶ。同じフォルダへのコピーでも複製できる。
- 連番は ` (1)` から始め、使用済みなら ` (2)`、` (3)` と増やす。通常のファイルは最後の拡張子の直前に付ける。例: `memo.md` → `memo (1).md`、`archive.tar.gz` → `archive.tar (1).gz`。
- フォルダと拡張子のない名前には末尾に付ける。先頭のドットだけを含む隠しファイルは拡張子なしとし、`.env` → `.env (1)` とする。
- 生成した名前は実際の作成時にも衝突を確認し、他の操作との競合で既存項目を上書きしない。結果には実際に作成した名前を表示する。
- フォルダをそのフォルダ自身または配下にコピーする操作は引き続き拒否する。

## 2. 切り取り時の同名確認

- 切り取りの貼り付け先に同名項目がある場合は、名前を変えて移動するかキャンセルするかを選べる確認画面を表示する。上書きとフォルダ結合は行わない。
- 名前を変える場合、コピーと同じ規則で空いている連番名を候補として表示する。ユーザーは名前を編集できる。
- 入力名が不正またはすでに存在する場合は移動せず、理由を表示する。キャンセル時・失敗時は元の項目と切り取り予約を維持し、成功後のみ予約を解除する。
- 元と同じフォルダに切り取りを貼り付けた場合は移動せず、その旨を表示する。同名確認や名前変更は行わず、切り取り予約も維持する。
- フォルダ自身またはその配下への移動は拒否する。シンボリックリンクはリンク自体を移動する。

## 3. F2・右クリックによる名前変更

- アクティブペインで選択中の1項目に `F2` を押すか、ファイル・フォルダ・シンボリックリンク上の右クリックメニューから「名前を変更」を選ぶと、現在の名前を入力済みの名前変更画面を開く。名前を変える対象はリンクそのものであり、リンク先を変更しない。
- 空名、空白のみ、`.`、`..`、`/` やNULを含む名前は拒否する。既存項目への上書き・結合は行わず、同名がある場合は理由を表示する。
- 元の名前のまま確定した場合とキャンセル時は変更せずに終了する。対象の消失、権限不足、その他の失敗時はエラーを表示し、既存項目を削除しない。
- 成功後は同じディレクトリを表示するペインを更新し、操作元ペインでは変更後の項目を選択する。キャンセル・終了後は元のペインにフォーカスを戻す。
- コピーまたは切り取り予約中の項目自身をこのアプリで名前変更した場合は、成功後に予約先を新しいパスに更新する。失敗・キャンセル時は変更しない。
- パス入力欄での編集を妨げない。名前変更処理にはGIOを使用し、シェルを使わない。

## 4. 受け入れ条件

- [ ] 同一フォルダや別フォルダに同名の項目を繰り返しコピーすると、拡張子・隠しファイル・フォルダの規則どおり連番が付き、既存項目は変化しない。
- [ ] 切り取り先の衝突時に候補名の編集またはキャンセルができ、上書きされない。成功後のみ切り取り予約が解除される。
- [ ] 同一フォルダへの切り取り貼り付けは何も移動せず、子孫へのコピー・移動は拒否する。
- [ ] ファイル・フォルダ・シンボリックリンクの名前を `F2` と右クリックメニューで変更し、変更後の項目が選択される。
- [ ] 同名・不正名・権限不足・対象消失・キャンセル時に既存項目が変更・削除されない。
- [ ] コピー・切り取り予約中の項目を名前変更しても、更新された名前で貼り付けられる。

## 5. 対象外

上書き、フォルダ結合、複数選択、外部アプリとのクリップボード連携、ドラッグ移動、完全削除、操作の取り消し。
