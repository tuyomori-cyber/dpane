# dir-group-webUI 仕様書 v0.1.3

- 作成日: 2026-11-04
- 位置づけ: [v0.1.2](specification_v0.1.2.md) を継承し、通常のファイル操作による実行可能バイナリの扱いを変更する。矛盾する場合は本版を優先する。

## 1. 通常のファイル操作

- ファイルのダブルクリック・`Enter`・右クリック「開く」は、実行権限があり、内容がELF形式の実行可能ファイルまたは共有オブジェクトと判別できる場合、実行確認を表示する。AppImageを含む。
- バックエンドでローカル通常ファイルを検証し、実行権限およびELFヘッダーの種別を確認する。拡張子や実行権限だけでは判別しない。`.desktop` は自動実行の対象外とする。
- それ以外のPDF・画像・Markdownなどの文書、スクリプト、権限のないファイルや判別できないファイルは、従来どおり既定アプリで開く。既定がなければアプリ選択を表示する。
- 右クリック「別のアプリで開く」・`Ctrl+Shift+O` は判定に関係なくアプリ選択を表示する。右クリック「実行」・`Ctrl+Shift+E` は引き続き明示的な実行操作とする。

## 2. 実行時の扱い

- 自動判別による起動でも、実行前の確認、キャンセル時の中止、確認後の対象・権限の再検証、シェルを使わない引数なしの起動はv0.1.2に従う。
- ファイルの種別は確認後にも再検証し、変わっていた場合は実行を中止する。
- 実行時の引数、ターミナル、プロセス管理、`.desktop` ランチャーの実行は対象外。起動後の成功を保証しない。

## 3. 受け入れ条件

- [ ] 実行権限のあるAppImage・ELF実行可能ファイルはダブルクリック・`Enter` で実行確認が表示され、承認後に起動する。
- [ ] キャンセルすると実行せず、元のペインへフォーカスが戻る。
- [ ] PDF・Markdown・画像、実行権限のある文書やスクリプトは従来どおり既定アプリで開く。
- [ ] 実行権限のないELFは自動実行せず、既定アプリで開くかアプリ選択を表示する。
- [ ] 「別のアプリで開く」と明示的な「実行」は従来どおり利用できる。
- [ ] 確認中に対象が変更された場合は自動実行しない。
