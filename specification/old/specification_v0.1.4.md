# dir-group-webUI 仕様書 v0.1.4

- 作成日: 2026-11-04
- [v0.1.3](specification_v0.1.3.md) を継承し、ファイル操作を追加する。

## 操作

- 選択中の1項目（ファイルまたはフォルダ）を `Ctrl+C` でコピー、`Ctrl+X` で切り取り予約し、アクティブペインの表示フォルダへ `Ctrl+V` で貼り付ける。切り取り元は貼り付け完了まで移動しない。
- コピー・切り取りの対象はアプリ内で保持する。テキスト入力中のショートカットは通常のテキスト操作とする。外部アプリとのクリップボード連携と複数選択は本版の対象外とする。
- `Delete` は選択中の1項目を確認後にGIOのゴミ箱へ移す。ゴミ箱が利用できない場合はエラーとし、完全削除には切り替えない。
- 同名の対象が貼り付け先にある場合は上書き・結合せずエラーとする。貼り付け元と先が同一の場合もエラーとする。
- シンボリックリンクはリンク自体を対象とし、リンク先をコピー・移動・削除しない。フォルダのコピーは中身もコピーする。フォルダ自身またはその配下への貼り付けを拒否する。
- 操作結果・エラーを表示し、影響を受けた表示ペインの一覧を更新する。コピー中の失敗で途中のコピー先が残った場合はその旨を示す。切り取り成功後のみ切り取り予約を解除する。
- 同時に複数の変更操作は開始しない。長時間操作はUIをブロックしない。

## 今回の対象外

ドラッグ移動、複数選択、外部アプリとのクリップボード連携、上書き・フォルダ結合、完全削除、操作の取り消し、進捗表示・中断、名前変更。

## 受け入れ条件

- [ ] 別ペインへファイルとフォルダをコピー・切り取り・貼り付けでき、切り取りは成功後のみ元がなくなる。
- [ ] 同名項目を上書きせず、同一・子孫フォルダへの貼り付けを拒否する。
- [ ] シンボリックリンクのリンク先を変更しない。
- [ ] ゴミ箱移動は確認後だけ行い、キャンセル・エラー時に完全削除しない。
- [ ] 対象の消失やアクセス権不足などはエラー表示し、表示を更新する。
- [ ] パス入力中はテキストのコピー・貼り付け・削除が引き続き使える。
