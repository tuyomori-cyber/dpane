# dir-group-webUI 仕様書 v0.1.8

- 作成日: 2026-11-04
- [v0.1.7](specification_v0.1.7.md) を継承し、パス入力欄のフォルダ補完を追加する。

## パス補完

- パス欄の入力に応じ、指定された親フォルダの直下から部分一致するフォルダを取得し、入力欄の下に候補を表示する。ファイルは対象外とする。
- 対象は絶対パス、`~`、`~/` から始まる現在のユーザーのホームパスとする。`~/` は表示上維持し、バックエンドで展開する。`~user` と相対パスは対象外とする。
- 入力欄にフォーカスがあるときの修飾キーなし `Tab` は補完に使う。候補が複数なら共通部分まで、1つならその名前と `/` まで補完する。候補がなくてもフォーカスは移さない。
- 入力欄以外の `Tab` と `Shift+Tab` は従来どおりフォーカス移動に使う。入力欄の `Shift+Tab`、既存の `Ctrl+Tab` / `Ctrl+Shift+Tab` も維持する。
- `↑` / `↓` で候補を選び、`Enter` またはクリックで入力欄へ反映する。選択中でない `Enter` は従来どおりフォルダへ移動する。`Escape` は候補を閉じる。
- ペインヘッダーの「移動」ボタンは設けず、パス欄の `Enter` で移動する。親フォルダへ移動する `↑` ボタンは維持する。
- 右上の「ペインを閉じる」ボタンを設けず、各ペインのパス欄の右の `×` でそのペインを閉じる。`Ctrl+Shift+W` によるアクティブペインの削除と、最後のペインを閉じたときの終了は維持する。
- 補完はカーソル位置のパス要素を対象とし、その後ろの `/` 以降は維持する。大文字・小文字は区別する。隠しフォルダはその要素が `.` で始まるときのみ候補に含める。
- 入力後150ms程度の遅延を設け、ペイン・要求ID・入力内容とカーソル位置が一致しない古い応答は破棄する。応答待ちの `Tab` は最新入力の結果が到着したときに処理する。
- 表示候補は最大100件とし、共通部分は表示上限に関係なく全候補から求める。読み取れない・存在しないフォルダは候補なしとし、入力やフォーカスを変更しない。
- GIOと既存の限定メッセージを使用し、候補取得はUIをブロックしない。ペイン閉鎖・フォーカス移動・一覧更新後も他のペインの入力を変更しない。

## 受け入れ条件

- [ ] 絶対パスと `~/` の1件・複数件・候補なし・隠しフォルダで候補と補完が動作する。
- [ ] Tab、Shift+Tab、Ctrl+Tab、矢印、Enter、Escape、クリックが上記どおり動作する。
- [ ] 応答待ちの入力変更・カーソル移動・ペイン切替・閉鎖で古い候補が表示・適用されない。
- [ ] 一覧更新中も入力中のパスとフォーカスが維持される。
- [ ] 100件を超える場合も全候補を使って共通部分を算出する。
