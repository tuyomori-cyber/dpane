# Dpane 仕様書 v0.1.17

- 作成日: 2026-11-05
- [v0.1.16](specification_v0.1.16.md) を継承し、起動時のペイン数の選択を追加する。以前の固定3ペインに関する記述より本版を優先する。

## 起動時のペイン数

- 「表示」メニューから、次回起動時に開くペイン数を1〜4で選択できる。変更は現在開いているペインや配置には反映せず、次回起動時から適用する。
- 選択値は既存の表示設定とともに `dpane/settings.json` に保存・復元する。設定ファイルがない、壊れている、または値が1〜4の整数でない場合は従来どおり3ペインとする。
- 初期ペインのフォルダは順にホーム、`~/Downloads`、`~/Documents`、`~/Pictures` とする。存在しないフォルダはそのペインにエラーを表示する。
- 配置は、1ペインでは単独表示、2ペインでは左右分割、3ペインでは左右分割の片側を上下分割、4ペインでは左右の各列を上下分割する。
- 既存のペイン追加・削除、最大8ペイン、分割方向、境界ドラッグは維持する。ペインの配置やフォルダの永続化は含めない。

## 受け入れ条件

- [ ] 「表示」メニューで1〜4を選ぶと設定が保存され、再起動時に選択した数のペインが開く。
- [ ] 1、2、3、4ペインがそれぞれ単独、左右、片側を上下、2×2の配置で開く。
- [ ] 設定が未作成・破損・範囲外の場合は3ペインで起動する。
- [ ] ペイン数の変更時に、現在のペインやファイル操作の状態を変更しない。
