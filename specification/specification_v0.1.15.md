# Dpane 仕様書 v0.1.15

- 作成日: 2026-11-04
- [v0.1.14](specification_v0.1.14.md) を継承し、ショートカット案内の表示設定を追加する。

## ショートカット案内の表示

- 表示メニューのチェックボックスで、全ペインの情報行に表示される `↑↓ / Enter / Backspace / F5 · Ctrl+Tab / Alt+1〜3` を表示・非表示にする。
- 項目件数と選択件数は引き続き表示する。初期状態は案内を表示し、設定の保存・復元は行わない。
- 表示を切り替えても、エラーやファイル操作の結果、選択状態を変更しない。

## 受け入れ条件

- [ ] ショートカット案内だけが全ペインで切り替わり、件数と選択件数が表示される。
- [ ] 一覧更新・選択変更後も設定が維持され、エラーや操作結果が切替時に消えない。
