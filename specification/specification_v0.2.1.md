# Dpane 統合仕様書 v0.2.1

- 対象: Xubuntu 24.04 / Xfce / X11、単一ウィンドウのファイル管理アプリ。
- 本書はv0.1.0〜v0.2.0の有効な要件とv0.2.1の変更を統合した現行仕様とする。版間で変更された要件は新しい版を優先して反映する。旧仕様書は履歴として残す。
- 状態: v0.1.24までの機能は実装済み。基本操作や一部の操作は実機確認済みだが、全受け入れ条件の実機確認は完了していない。v0.2.0のペインの最大化・最小化はユーザーが実機動作を確認済み。v0.2.1のフォルダ一覧、番号・フォルダ名表示および最小化中の文字サイズはユーザーが実機確認済み。最大化を維持した次 / 前のペイン移動は実装済み・実機未確認。個別条件の全確認は未完了。個別の確認状況は `todo.md` と `report/` を参照する。

## 1. 目的と構成

複数のディレクトリを単一アプリ内の独立したペインに表示し、上下・左右に分割して素早く閲覧、移動、ファイル操作できる軽快な環境を提供する。複数のX11ウィンドウを同期する方式ではない。

- フロントエンドはHTML/CSS/JavaScript、アプリはPython + GTK3 + WebKitGTKを使用する。GIOなどLinuxの既存機能を利用する。
- ファイルシステム操作はバックエンドに分離し、WebKitGTKの用途限定メッセージで接続する。外部公開HTTP APIや任意のシェルコマンドを実行する汎用APIは設けない。
- 単一の通常ウィンドウとして移動、最小化、リサイズできる。起動感と操作感は実機で判断する。

## 2. ペインとレイアウト

- 保持するペインのうち0〜8ペインを表示する。各ペインは独立したフォルダ、選択、履歴、更新日時の表示状態を持つ。クリックまたはキーボードでアクティブペインを切り替え、青枠と操作対象を対応させる。
- 各ペインの `||` / `＝` は、そのペインを分割して右 / 下に追加する。ショートカットはアクティブペインに作用する。新規ペインは元のパスを引き継いで一覧を取得し、選択は引き継がず、アクティブになる。原則として分割前の領域を等分する。
- 最小化中を含め保持するペインが8個のときは追加ボタンを無効にし、ショートカットでも追加しない。左右・上下を入れ子にでき、境界ドラッグでサイズを変更できる。狭い領域でもレイアウトが破綻しないようにする。
- 各ペインの `×` はそのペインを閉じる。削除後は残存側を拡張し、他のペインのフォルダと選択を維持する。表示ペインが残る場合、削除後のアクティブ対象は残存側の隣接ペイン、残存側が分割領域ならその表示順の先頭とする。最小化中のペインが残っている場合、最後の表示ペインを閉じても終了せず表示ペインがない状態になる。保持するペインがなくなった場合はアプリを終了する。ファイルやフォルダは削除しない。
- 起動時ペイン数は「表示」から1〜4を選択する。初期値は3。配置は1が単独、2が左右、3が左右の片側を上下、4が2×2。初期フォルダは順にホーム、`~/Downloads`、`~/Documents`、`~/Pictures`。存在しない場合は当該ペインにエラーを表示する。設定変更は次回起動時に適用する。
- 表示上のペイン番号は現在の表示順で付け直し、ペインの見出しとフォルダ一覧の両方に「1: Downloads」のように番号とフォルダ名を表示する。最小化中のペインは番号を表示しない。通常時の次 / 前のペイン移動は表示中のペインを表示順に循環し、番号指定は表示中の1〜8番目に移動する。表示ペインがない場合、ペイン切替やペインを対象とするファイル操作は行わない。


### 2.1 ペインの最大化

- アクティブペインだけを作業領域いっぱいに表示し、解除すると元の表示レイアウトに戻す。最大化は表示の切替として扱い、既存の分割木と分割比率を変更しない。最小化とは別の仕組みとする。
- 最大化中にペインを追加または削除するときは、まず最大化を解除してから操作する。`Ctrl+Tab` / `Ctrl+Shift+Tab` によるペイン移動は最大化を維持し、最小化中を除く次 / 前のペインへ表示順で循環する。`Alt+数字` によるペイン指定は先に最大化を解除する。設定変更された対応ショートカットも同様とする。
- 各ペインの `□` / `❐` で最大化 / 解除する。最大化中に最小化・復元するときも先に最大化を解除する。ブックマークで別のペインを指定した場合は最大化を解除する。

### 2.2 ペインの最小化と復元

- 最小化したペインは表示用の分割木から外し、パス、移動履歴、選択、更新日時表示などペインの状態を保持する。空いた領域は残存側が使う。ファイルやフォルダは削除しない。
- 最小化中のペインを選んで復元できるフォルダ一覧を、表示ペインがない場合も操作できる場所に設ける。
- 表示中のペインがある場合、復元対象をアクティブペインの右に分割して表示する。元の分割位置に戻す必要はない。表示中のペインがない場合は復元対象を単独表示する。
- 最後の表示ペインも最小化できる。全ペインが最小化された場合もアプリを終了せず、復元一覧を使用できる。最小化中のペインはアプリ終了時に破棄し、次回起動時に復元しない。
- 各ペインの `−` で最小化し、フォルダ一覧から復元する。復元したペインをアクティブにする。最小化中のペインも8ペイン上限に含める。


### 2.3 フォルダ一覧

- メニューとペイン領域の間に、表示中・最小化中の全ペインのフォルダ名を開いた順に横並びで表示する。並び順はペインの表示順や番号とは一致しなくてもよく、最小化・復元しても変わらない。
- 番号とフォルダ名をボタンに表示し（最小化中はフォルダ名のみ）、ポインターを合わせるとパスを示す。移動後は名前とパスを更新する。同じフォルダを複数開いた場合も同じ名前を個別に表示し、それぞれのペインを操作できる。長い名前は省略し、幅に収まらない場合は横スクロールできる。
- 表示中のペインをクリックすると最大化し、最大化中のペインをクリックすると解除する。別のペインが最大化されて一時的に隠れている場合は、クリックしたペインの最大化表示に切り替える。最小化中のペインをクリックすると復元する。キーボードによるペイン移動は2.1に従う。
- 通常表示中、最大化中、最小化中を色や印で区別し、最小化中の文字は少し小さくする。表示中のペインがないときも一覧から復元できる。従来の「最小化したペイン」メニューは一覧に置き換える。

## 3. ディレクトリ閲覧とパス入力

- 各ペインでフォルダ内容を一覧表示し、フォルダの移動、一覧の更新、項目選択を行う。一覧取得は最大1,000件とし、上限到達時はその旨を示す。
- パス欄の `Enter` で入力先に移動する。`↑` ボタンと一覧操作中の `Backspace` は親フォルダへ移動する。パス欄を未フォーカス状態から左クリックすると全選択し、再クリックで任意の位置にカーソルを置ける。
- `←` はそのペインの直前の表示フォルダに戻る。履歴は移動成功時のみ更新し、同じフォルダの再表示・更新では増やさない。ブックマーク移動も対象。履歴がない場合はボタンを無効にし、戻り先が開けない場合は現在の表示と履歴を維持してエラーを示す。履歴はペインを閉じるかアプリ終了時に破棄する。

### 3.1 パス補完

- 絶対パス、`~`、`~/` から始まる現在のユーザーのホームパスを対象とする。`~user` と相対パスは対象外。表示上の `~/` は維持する。
- 入力要素の親フォルダ直下から部分一致するフォルダを候補として表示する。ファイルは含めない。大文字・小文字は区別し、隠しフォルダは入力要素が `.` で始まる場合に含める。
- パス欄の修飾キーなし `Tab` は複数候補の共通部分、または1候補の名前と `/` まで補完する。候補がなくてもフォーカスを移さない。`↑` / `↓` で候補を選び、`Enter` またはクリックで反映する。未選択時の `Enter` はフォルダ移動、`Escape` は候補を閉じる。`Shift+Tab` は通常の前要素への移動とする。
- カーソル位置の要素を補完し、後ろの `/` 以降を維持する。候補は最大100件表示し、共通部分は全候補から求める。入力後およそ150msの遅延を設け、古い応答を破棄する。応答待ちのTabは最新結果に対して処理する。取得は非同期とし、アクセス不能な場合は候補なしとして入力やフォーカスを変更しない。

## 4. 一覧表示と選択

- 更新日時を表示していない一覧は、ペイン幅に応じて1〜3列で左から右、次に下へ項目を並べる。表示領域を超えた項目は縦スクロールで閲覧する。更新日時を表示すると当該ペインは1列になる。
- 一覧操作中の `↑` / `↓` は同じ列内、`←` / `→` は同じ行の隣接列を選択する。対応する項目がない場合は選択を維持する。`Shift` と矢印の組み合わせはアンカーから一覧順の範囲を選択する。

- 通常クリックで1項目を選択し、`Ctrl` + クリックで個別に追加・解除、`Shift` + クリックまたは `Shift` + 矢印でアンカーからの範囲を選択する。選択数にアプリ固有の上限は設けず、一覧取得上限の範囲で選択できる。
- 一覧の空白クリックはそのペインの選択を解除し、空白からのドラッグは矩形に重なった行を選択する。項目上の長押しによる範囲選択は行わない。選択済み項目の右クリックは選択を維持し、未選択項目ではその項目だけを選択する。
- 同じフォルダの再読込では残存項目の選択を維持する。非表示になった隠し項目は選択から外し、再表示しても復元しない。アクティブと非アクティブのペインでは選択色を区別する。
- 「表示」メニューで名前が `.` で始まるファイルとフォルダを全ペイン一括で表示 / 非表示にする。初期値は表示。パス補完の隠しフォルダの扱いは独立する。
- 各ペインの `Update times` と対応するショートカットで、そのペインだけ最終更新日時を表示 / 非表示にする。初期値は非表示で、取得できない日時は `—`。日時はローカル時刻 `YYYY-MM-DD HH:mm` で表示する。同一ペインでの移動・更新時は維持し、新規ペイン・再起動では非表示とする。

### 4.1 インクリメンタル検索

- 一覧にフォーカスがある状態で文字を入力すると、そのペインの右下に小さな検索欄を表示する。`Ctrl+F` では空の検索欄を開け、日本語IMEの入力にも利用できる。検索欄は空欄時の案内文を表示しない。
- ペインに現在表示されているファイルとフォルダの名前を対象に、大文字・小文字を区別せず前方一致で検索する。入力のたびに一致する最初の項目を選択し、画面外の場合は見える位置へスクロールする。非表示の隠し項目と一覧取得上限1,000件を超えた項目は検索しない。
- 検索欄の `↓` / `↑` は一致候補を次 / 前へ循環する。`Enter` は検索欄を閉じて一致項目を開き、`Escape` は選択を維持して検索欄を閉じる。`Backspace` は検索文字列を編集する。
- 一致項目がない場合は文言を表示せず、選択を維持する。この状態で `Enter` を押しても以前の選択項目を開かない。検索欄を閉じた後の `Backspace` は従来どおり親フォルダへ移動する。
- 別ペインへの移動やフォルダ移動・更新時には検索欄を閉じる。検索欄の `Ctrl+Tab` / `Ctrl+Shift+Tab` はペイン移動として扱う。
- `Ctrl+F` とユーザーが設定した既存ショートカットが競合する場合は、既存ショートカットを優先する。パス欄やメニューへの入力は検索対象としない。

## 5. ファイルを開く・実行する

- フォルダのダブルクリック / Enter はフォルダに移動する。通常ファイルはGIOで既定アプリに渡す。既定アプリがない場合はGTKのアプリ選択を表示し、キャンセル時は開かない。失敗や対応アプリなしの場合は理由を表示する。
- 実行権限のあるELF形式の実行可能ファイルまたは共有オブジェクト（AppImageを含む）は、通常の「開く」操作で実行確認を表示する。拡張子や実行権限だけでは判定しない。スクリプト、実行権限のないELF、判別不能なファイル、`.desktop` は自動実行せず既定アプリで開く。
- 「別のアプリで開く」は対象を選択したアプリで開き、既定の関連付けは変更しない。「既定のアプリを変更」は種類ごとのシステムの関連付けを変更し、他のアプリにも影響する旨を示す。キャンセル時は変更せず、設定時は自動で開かない。対象の種類を確認できない、または選択中に変化した場合はエラーとする。
- 「実行」は実在するローカル通常ファイルの実行権限を検証し、パスを示す確認画面で承認された場合のみ行う。`.desktop` は対象外。確認後にも対象と権限、自動判定時は種別を再検証する。シェルを使わず引数なしで直接起動し、作業ディレクトリは対象の親とする。終了監視、引数指定、対話端末、インタープリターの指定は対象外。実行プログラムはユーザー権限で動作する。
- 開く、別アプリ、実行、名前変更は単一選択時に有効とする。

## 6. ファイル操作

- 安全設計の基本方針は、操作ミスや実装上の不具合によるデータ損失を防ぎ、ユーザーが明示的に承認した操作の結果を過剰に制限しないこととする。
- `Ctrl+C` / `Ctrl+X` で選択したファイル・フォルダのコピー / 切り取りをアプリ内に予約し、`Ctrl+V` でアクティブペインのフォルダへ貼り付ける。切り取り元は貼り付け完了まで変更しない。パス入力中のコピー等は通常のテキスト編集とする。外部アプリとのクリップボード連携は対象外。
- 複数項目を対象にでき、操作直前に各対象を検証する。失敗した項目があっても他の項目は続行し、成功・失敗の件数と失敗対象を表示する。切り取り予約は成功項目のみ解除する。同じフォルダへの切り取り貼り付けは変更せず予約を維持する。
- 同名項目がある場合、各対象について実行前に確認する。異なる通常ファイル同士では「連番を付ける」「上書き」「キャンセル」、同一ファイルやフォルダ・リンク等を含む場合は連番またはキャンセルのみとし、フォルダ結合や自身の上書きはしない。いずれかでキャンセルした場合は実行を開始しない。
- 連番は `memo (1).md`、`archive.tar (1).gz`、`.env (1)`、`資料 (1)` のように付け、使用済みなら次の番号を使う。作成時にも衝突を確認し、結果に実際の名前を表示する。
- 上書きはユーザーが承認し、上書き前の確認で対象の変更が検出されなければ実行する。変更を検出した場合は中止する。最終確認から置換までに余計な待機処理を挟まない。ただし、最終確認後から置換までの間に別プロセスが対象を更新した場合、その更新が失われる競合の完全な防止は保証しない。
- コピーの上書きは貼り付け先内の一時ファイル完成後に置換する。切り取りの上書きは同一ファイルシステムに限り、異なる場合は失敗として元と既存項目を保持する。コピー失敗時に途中のコピーが残れば場所を示す。
- シンボリックリンクはリンク自体を対象とし、リンク先を変更しない。フォルダ自身またはその配下へのコピー・移動を拒否する。フォルダのコピーは中身も対象とする。
- `Delete` は選択項目の件数と一覧を示し、確認後にGIOのゴミ箱へ移動する。既定応答はキャンセル。利用できない場合も完全削除に切り替えない。
- 一覧の右クリックから表示中フォルダに新規フォルダ / 空ファイルを作成できる。`F2` または右クリックから1項目の名前を変更できる。空名、空白のみ、`.`、`..`、`/` やNULを含む不正名を拒否し、同名項目を上書きしない。キャンセルまたは元の名前での確定は変更しない。成功時は関連するペインを更新し、名前変更後の項目を操作元で選択する。予約中の項目を名前変更した場合は予約パスを更新する。
- 操作結果やエラーを表示し、関連する一覧を更新する。コピー・移動・ゴミ箱移動の処理中に失敗した場合は、成功・失敗の件数と、各失敗項目のパス・理由をスクロール可能な画面に表示する。異なるファイルシステム間の上書き移動は理由を明示する。複数の変更操作を同時に開始せず、長時間処理でUIをブロックしない。
- 項目行からのドラッグはコピーとする。選択済み行なら全選択項目、未選択行ならその項目を対象とし、押したまま待ってからでも同じ。別ペインへのドロップはその表示フォルダへコピーし、同名時は貼り付けと同じ確認を行う。外部アプリにはファイルURIをコピーとして渡す。

## 7. ブックマーク

- 各ペインのパス欄左側の `☆` / `★` で現在のフォルダを登録 / 解除し、全ペインの状態表示を更新する。未登録は `☆`、登録済みは `★`。
- 上部の「☆ ブックマーク」は必要時に一覧をポップアップ表示し、外側クリックで閉じる。空の場合はメッセージを表示する。名前のクリックはアクティブペインで開き、`⊞` は新規ペインで開く。表示ペインがない場合は、名前のクリックで新規ペインを追加して開く。最小化中を含む8ペイン上限を超えて追加しない。表示ペインがなく上限に達しているときは追加せず理由を示す。
- 項目の右クリックメニューから開く、新規ペインで開く、表示順のペインを指定する「送る」、登録解除を行える。送信先は「Pane 1へ送る」のように表示する。「送る」はファイルのコピー・移動ではなく、指定ペインの表示先を変える。サブメニューは現在のペイン構成を反映し、画面端では位置を調整する。
- ブックマークはユーザー設定ディレクトリの `dpane/bookmarks.json` にJSON形式で保存し、起動時に復元する。正規化した絶対パスを登録順に保持し、同じ実体の重複を防ぐ。表示名はフォルダ名から生成し、登録数に固定上限は設けない。保存は一時ファイルからの置換で行う。
- 存在しなくなったフォルダも一覧に残す。開けない場合はエラーを示して現在のペイン表示を維持し、一覧から解除できる。

保存データは `{"version": 1, "bookmarks": [{"path": "/home/user/Documents"}]}` の形式とする。

## 8. ショートカットの変更

- UTF-8のJSONファイル `~/.config/dpane/keybindings.json` に、変更する操作IDとキーの組み合わせを記述する。`XDG_CONFIG_HOME` が設定されている場合は、その配下の `dpane/keybindings.json` を使用する。
- ファイルがない場合や操作IDが記載されていない場合は、その操作の初期値を使用する。ファイルの変更はアプリの再起動時に読み込む。
- 変更できる操作は次に限定し、各操作が有効な場所や実行内容は従来どおりとする。パス欄で利用できる操作は、変更後もパス欄で有効とする。

| 操作ID | 初期値 | 操作 |
| --- | --- | --- |
| `splitRight` | `Ctrl+Shift+L` | アクティブペインの右に追加 |
| `splitDown` | `Ctrl+Shift+J` | アクティブペインの下に追加 |
| `closePane` | `Ctrl+Shift+W` | アクティブペインを閉じる |
| `toggleTimes` | `Ctrl+T` | 更新日時を表示 / 非表示 |
| `showShortcuts` | `Ctrl+K` | ショートカット一覧を開く / 閉じる |
| `nextPane` | `Ctrl+Tab` | 次のペインへ移動 |
| `previousPane` | `Ctrl+Shift+Tab` | 前のペインへ移動 |
| `pane1`〜`pane8` | `Alt+1`〜`Alt+8` | 表示順の1〜8番目のペインへ移動 |
| `chooseApplication` / `execute` | `Ctrl+Shift+O` / `Ctrl+Shift+E` | 別のアプリで開く / 実行を確認 |

- 組み合わせは `Ctrl`、`Shift`、`Alt`、`Meta` の少なくとも一つと、英字・数字・`F1`〜`F12`・`Tab` を `+` でつないで指定する。大文字・小文字と修飾キーの順番は問わない。同じ修飾キーの重複は認めない。
- 割り当て同士の重複、固定の `Ctrl+C` / `Ctrl+X` / `Ctrl+V` / `Shift+Tab` との重複、未知の操作ID、不正な書式や読み込みエラーがある場合は理由を表示し、その起動中はすべて初期値を使用する。設定ファイルは変更しない。
- OSやウィンドウマネージャーが先に取得する組み合わせは利用できない場合がある。設定時にはパス欄などでの文字編集との競合にも注意する。
- ヘルプのショートカット一覧、ヘルプメニュー、ペインのボタンと情報行の案内には、適用中の割り当てを表示する。変更対象外のショートカットは従来どおりとする。

- 設定・ヘルプメニューはメニュー外をクリックすると閉じる。ショートカット一覧は表示中に同じショートカットを押すと閉じる。

変更対象外の主なキーは次のとおりとする。

| キー | 操作 |
| --- | --- |
| 矢印、`Shift` + 矢印 | 一覧の選択 / 範囲選択 |
| 文字入力 / `Ctrl+F` | 一覧の名前検索を開始 |
| `Enter` / `Backspace` / `F5` | 項目を開く / 親フォルダ / 更新 |
| `Ctrl+C` / `Ctrl+X` / `Ctrl+V` | コピー / 切り取り / 貼り付け |
| `Delete` / `F2` | ゴミ箱へ移動 / 名前変更 |
| パス欄の `Tab` / `↑` / `↓` / `Enter` / `Escape` | パス補完の操作 |

### 8.1 初期値への復元

- メニューに「設定」を設け、「ショートカットを初期値に戻す」を選べるようにする。
- 選択すると設定ファイルの内容を空のJSONオブジェクト `{}` に置き換え、再起動せずに初期値を適用する。ヘルプと案内表示も更新する。
- 保存に失敗した場合はエラーを表示し、現在適用中の割り当てを維持する。ショートカットのGUI編集は本版の対象外とする。

## 9. 表示設定とメニュー

- 「表示」メニューでWebKit内の画面スケールを70〜150%、10%刻みで変更する。初期値は100%。GTK標準ダイアログとウィンドウ装飾は対象外。
- ショートカット案内は全ペインで表示 / 非表示を切り替える。初期値は表示。件数と選択件数は引き続き示し、切替時に選択やエラー・操作結果を消さない。
- スケール、隠し項目表示、ショートカット案内、次回起動時のペイン数はユーザー設定ディレクトリの `dpane/settings.json` に保存し、次回復元する。未作成・破損・不正値は該当項目を初期値にする。保存失敗時は現在の設定で操作を継続し、標準エラーに記録する。
- ヘルプのショートカット一覧はメニューまたは設定されたキーで開き、同じキー、`Escape`、閉じるボタンで閉じる。設定・ヘルプメニューは外側クリックで閉じる。

## 10. 受け入れ条件

以下は機能要件であり、チェックの有無は実機確認の記録を代替しない。

- 0〜8ペインの表示、分割、追加・削除、境界ドラッグ、フォーカスと、保持するペインがなくなった場合の終了が成立する。
- ペインの最大化・解除で分割木と比率が保たれ、追加・削除時の解除と、最大化を維持した次 / 前のペイン切替が仕様どおり動作する。
- ペインの最小化・右側への復元、全ペイン最小化、表示ゼロからの単独復元とブックマークによるペイン追加、最小化中の状態保持が仕様どおり動作する。
- フォルダ一覧の表示順、状態表示、パス表示、各状態からの最大化・解除・切替・復元が仕様どおり動作する。
- 起動時の1〜4ペインと設定復元、パス入力・補完、独立した移動履歴が仕様どおり動作する。
- 選択、範囲選択、隠し項目、更新日時が他のペインや入力を不意に変更しない。
- ペイン幅に応じた複数列表示と縦スクロール、日時表示時の1列表示、矢印選択が仕様どおり動作する。
- ファイル・フォルダの前方一致検索、候補の循環、Enter・Escape、該当なしの場合の扱い、IME入力とペイン切替が仕様どおり動作する。
- 既定アプリで開く、アプリ選択、既定アプリ変更、実行確認・再検証が仕様どおり動作する。
- 単一・複数項目のコピー、切り取り、貼り付け、同名確認、ゴミ箱、新規作成、名前変更、ドラッグコピーで、キャンセル・競合・権限不足・対象変化を安全に扱う。
- ブックマークの登録・解除、一覧、既存 / 新規ペインへの表示、保存・復元、存在しないフォルダの扱いが成立する。
- 指定操作のショートカット設定が再起動時に反映され、ヘルプと案内に反映される。重複・不正値で初期値を使い、GUIの初期化が動作する。
- GUI実機で操作感、OS側とのキー競合、狭いペイン、メニュー開閉を確認する。

## 11. 対象外

- ペインの配置・フォルダや更新日時表示状態の保存・復元、ペインの並べ替え・別ウィンドウ化、保持するペインの8個超。
- ショートカットのGUI編集、ブックマークの分類・名前変更・並べ替え・検索・同期・インポート / エクスポート。
- ファイルの完全削除、操作の取り消し、進捗表示・中断、外部アプリとのクリップボード連携、ドラッグ移動。
- 実行時の任意引数や端末指定、実行後のプロセス管理、汎用のシェルコマンド実行API。

## 検討中: ゴミ箱移動のUndo

- 実装は見送り。直近のDpaneによるゴミ箱移動を復元する案を検討する。複数項目ではゴミ箱移動に成功した項目だけを対象とする。
- 復元先の同名項目は上書きせず、ゴミ箱内の対象が外部操作で失われた場合や一部復元に失敗した場合は理由と結果を示す。テキスト入力中のCtrl+Zは入力の取り消しとする。
- GIOのゴミ箱移動はゴミ箱内の移動先を返さないため、同名項目や外部操作がある場合も正しい対象を特定できる方法と、複数ファイルシステムでの動作を実装前に検証する。
